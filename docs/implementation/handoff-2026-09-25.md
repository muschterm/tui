## User decisions recorded this session

- Terminals: explicit Take control; `$SHELL` interactive; x/vt + creack/pty; 10k-line memory-only scrollback.
- Git writes: hooks/filters/signing run like the CLI for writes (reads neutralise repo-local config); all Git writes refused while an agent holds the checkout; discard and amend included.
- Remote: non-interactive credentials only; switch carries changes per Git semantics with explicit confirmation; plain push to upstream (never forced); graph default HEAD+upstream with “All branches”.
- Editor: reearth/ygo v1.50.0; custom cell-native editor; autosave 750 ms idle / 3 s max, atomic rename; editable ≤1 MiB UTF-8.
- Merge/rebase: clean tracked tree required, never autostash; job-kind threads for agent resolution; Skip rebase-only with confirmation; non-interactive rebase only.
- Worktrees: inside the app home (`<home>/worktrees/<project>/<branch>-<id>`); always a new branch; one thread per worktree; Remove only when attached threads are Closed, branch kept, ignored-file deletion disclosed.
