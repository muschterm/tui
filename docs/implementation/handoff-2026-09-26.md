## Residual risks worth knowing

- Partial staging B1 window: another process changing the same index entry
  between the final recheck and `update-index` is not detectable (ADR 0025).
- `git --no-optional-locks diff` can still refresh stat data under
  `index.lock` (ADR 0025 Known limits); content is never at risk.
- Worktree Git-discovery ceilings are process-wide and do not cover Git run
  by agents or terminals inside a worktree (ADR 0024).
- The worktree `running`/`failed`/`retryable`/Stop-following paths and the
  partial-staging re-pin logic are covered by unit tests only; the PTY
  harnesses exercise the fast paths.
