# Share the behavior specification across three idiomatic reference apps

The repository will define one UI and interaction specification with complete reference applications in Go, Rust, and Bun, each including its native server and TUI, so future projects can adopt the design in their own language. Each implementation may use idiomatic internals while satisfying the same observable behavior and shared client/server contract; reusable libraries will be extracted when actual reuse justifies their boundaries. The user selected this direction over framework packages or a cookbook-only repository during the design interview on 2026-09-19, and delegated implementation order: Go is first. [Server ownership and transport](0003-background-server-attachable-clients.md) describe the subsequent architecture decision; database-file interchange is not implied.
